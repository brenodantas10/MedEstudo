São neurônios responsáveis pelo movimento

- 1º Neurônio Motor (Cortex) -> Manda sinal inibitório para 2º Neurônio
- 2º Neurônio Motor (Medula) -> Manda sinal estimulatório para o Músculo
- 3º Neurônio Motor (Tálamo) -> Manda sinal processado para o 1º neurônio
- Neurônios Sensitivos (No músculo)
	- Manda sinal excitatório para o 2º neurônio
	- Manda sinal excitatório para o 3º Neurônio

## Via Motora
- 1º Neurônio motor manda sinal do cortex
- 2º Neurônio motor recebe sinal e manda sinal para o músculo
- Músculo contrai
## Via Reflexa

## Via Sensitiva
- Após estiramento ou dor ou outra coisa
- Nervo sensitivo manda sinal para a medula
	- Pode estimular o 2ºNeurônio motor
	- Pode perpetuar sinal para o tálamo (3º Neurônio Motor)
- 3º Neurônio Motor processa sinal e manda para o Cortex (1º Neurônio Motor)

## Lesões
