Magnésio é um **Tampão** dos canais do **Túbulo Contorcido Distal** e Ducto Coletor dos Rins, **impedindo a excreção de potássio**.

## Fisiologia

### 1. Bloqueio dos Canais ROMK (Medula Renal Externa):
Os canais **ROMK** são as "portas de saída" por onde o potássio é secretado para o filtrado urinário. O magnésio livre dentro da célula funciona como um plugue físico para esses canais.
	• **Normomagnesemia** -> $\ce{Mg^{2+}}$ se liga ao canal pelo lado de dentro da célula renal e modula a saída de potássio, evitando o desperdício.
	• **Hipomagnesemia** -> ROMK não bloqueado -> Passagem livre de $\ce{K+}$ para urina -> Hipocalemia.

### 2. Atividade da Bomba de Sódio-Potássio (Na+/K+-ATPase):
O magnésio é um cofator obrigatório para a energia (ATP) que move essa bomba. Ela é responsável por colocar o potássio de volta para dentro das células renais. Se falta magnésio, a bomba perde eficiência, desregulando o gradiente necessário para manter o potássio no corpo
