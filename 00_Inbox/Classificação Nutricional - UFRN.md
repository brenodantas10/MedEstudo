Na dúvida, se cair no limite, considerar o diagnóstico mais benéfico.
- **Peso para a Idade**
	- < -3dp: Extremo baixo peso para a idade
	- < -2dp: Baixo peso para a Idade
	- -2 ˜ 2: Adequado para a Idade
	- > 2 dp: Adequado para a Idade
- **Estatura para a Idade**
	- < -3: Muito baixa estatura para a idade
	- < -2: Baixa estatura para a idade
	- >= -2: Estatura adequada para a Idade
- **IMC para a Idade** ou **Peso para Estatura** (Este último não usar para > 5 anos)
	- < -3: Magreza acentuada
	- < -2: Magreza
	- -2 ˜ 1: Eutrófico
	- Se < 5 anos
		- >1: Risco de Sobrepeso
		- >2: Sobrepeso
		- >3: Obesidade
	- Se >= 5 anos
		- >1: Sobrepeso
		- >2: Obesidade
		- >3: Obesidade grave
